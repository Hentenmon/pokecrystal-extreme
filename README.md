# Pokémon Extreme Crystal


This is a hack of Pokemon Crystal Kaizo+ that was made by me, but has less features (example, no pocket PC, no better box design), in case you wanna stick to the more authentic graphics of Pokemon Crystal.


# General Information

- Compile this hack by checking *INSTALL.md*
- Game has more diverse encounter pools, improved level up learnsets (TMs are way less important for playthroughs)
- Items (like berries, type boost items) are more accessible now and purchasable in marts
- Bad Pokemon have been buffed to be viable
- All trainers have been heavily buffed
- Amazing resource for damage calculating, trainer parties and encounters, in case you are nuzlocking, is Emi's CK+ calculator (https://emi.dev/ck+/#/calc/)
- Not a fitting game for an average player
- Forced level caps
- An average (good) player will defeat this in about 30 hours
- Also now a disassembly, since the source code of CK+ was never accessible
